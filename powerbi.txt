Practical 5: Introduction to Power BI, Basic Charts, Maps, Tables and Matrix
Aim: To study and demonstrate the introduction to Power BI, basic charts, maps, tables and matrix.
Procedure
1. Open Power BI Desktop.
2. Click Home → Get Data → Excel Workbook.
3. Select an Excel dataset and click Open.
4. Select the required sheet and click Load.
5. Explore Report View, Data View and Model View.
6. Select Clustered Column Chart from the Visualizations pane.
7. Drag Category into X-axis and Sales into Y-axis.
8. Select Bar Chart and drag Category into Y-axis and Sales into X-axis.
9. Select Pie Chart and drag Category into Legend and Sales into Values.
10. Select Donut Chart and add Category and Sales fields.
11. Select Map visual and drag City into Location and Sales into Size.
12. Select Table visual and drag Name, Category and Sales into it.
13. Select Matrix visual and drag Category into Rows, Region into Columns and Sales into Values.
14. Format the visuals using the Format pane.
15. Save the report using File → Save.
Important concepts
Concept	Description
Power BI	Business Intelligence and data visualization tool
Report View	Creates charts and reports
Data View	Displays imported data
Model View	Manages table relationships
Map	Displays geographical data
Table	Displays data in rows and columns
Matrix	Displays summarized data with rows and columns

Result: Successfully imported data and created basic charts, maps, tables and matrix visuals in Power BI.

Procedure D: Conditional Columns
1. Open Power Query Editor.
2. Select Add Column → Conditional Column.
3. Enter the new column name as Result.
4. Select the required column, such as Marks.
5. Select the operator greater than or equal to.
6. Enter 40 as the condition.
7. Enter Pass in the output field.
8. Enter Fail in the Else field.
9. Click OK.
10. Click Close & Apply.
Example:
Name	Marks	Result
Rahul	80	Pass
Amit	35	Fail
Priya	90	Pass

Equivalent M formula:
if [Marks] >= 40
then "Pass"
else "Fail"


Procedure E: M Language Introduction
1. Open Power BI Desktop and select Transform Data.
2. Open Power Query Editor.
3. Select View → Formula Bar.
4. Select a column and apply a transformation.
5. Observe the generated M code in the Formula Bar.
6. Open Home → Advanced Editor.
7. Observe the complete M language script.
8. Write or modify a simple M expression.
9. Click Done to apply the changes.
10. Click Close & Apply.
Example of M Language:
let
    Source = Excel.CurrentWorkbook(){[Name="Table1"]}[Content],
    ChangedType = Table.TransformColumnTypes(
        Source,
        {{"Marks", Int64.Type}}
    ),
    AddedColumn = Table.AddColumn(
        ChangedType,
        "Result",
        each if [Marks] >= 40 then "Pass" else "Fail"
    )
in
    AddedColumn


Important concepts
Concept	Meaning
Power Query	Tool used to clean and transform data
Append	Combines rows from multiple tables
Merge	Combines columns from related tables
Conditional Column	Creates a column based on conditions
M Language	Formula language used in Power Query
Advanced Editor	Displays and edits the complete M code
Close & Apply	Applies transformations to Power BI

Result: Successfully performed number transformations, appended and merged tables, created conditional columns and explored M language in Power Query.

Important Difference: Append vs Merge
Append	Merge
Combines rows	Combines columns
Tables should have similar structures	Tables should have a common matching column
Works vertically	Works horizontally
Example: January + February sales	Example: Student details + Student marks











Append – Vertical combination











Merge – Horizontal combination
