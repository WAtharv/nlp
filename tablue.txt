Practical 9: Introduction to Tableau, Data, Sets, Sorting, Filtering and Parameters
Aim: To study and demonstrate Introduction to Tableau, Data in Tableau, Sets, Sorting, Filtering and Parameters.
Procedure A: Introduction to Tableau and Data
1. Open Tableau Desktop or Tableau Public.
2. Select Connect → Microsoft Excel.
3. Browse and select your e-commerce dataset.
4. Open the required worksheet from the Data Source page.
5. Explore Dimensions and Measures in the Data pane.
6. Identify discrete fields (blue) and continuous fields (green).
7. Drag Category into Columns and Sales into Rows.
8. Select Show Me to explore different chart types.
9. Save the workbook using File → Save As.
Procedure B: Creating Sets
1. Open a new worksheet.
2. Right-click the Category field in the Data pane.
3. Select Create → Set.
4. Enter the Set Name as Top Categories.
5. Open the General tab and select the required categories.
6. Alternatively, open the Top tab and select Top 3 by SUM(Sales).
7. Click OK to create the Set.
8. Drag the Set into Rows or Colour to display the selected categories.



salesforcefaqs.com


Procedure C: Sorting
1. Drag Category into Rows.
2. Drag Sales into Columns.
3. Select the Sort Descending icon from the toolbar.
4. Alternatively, right-click Category and select Sort.
5. Choose Sort By Field → Sales → Sum → Descending.
6. Observe the categories arranged according to sales.
Procedure D: Filtering
1. Drag Category into Rows.
2. Drag Sales into Columns.
3. Drag Category into the Filters shelf.
4. Select the required categories.
5. Click OK to apply the filter.
6. Right-click the Category filter and select Show Filter.
7. Use the filter card to select different categories.








trailhead.salesforce.com


Procedure E: Creating Parameters
1. Right-click in the Data pane.
2. Select Create → Parameter.
3. Enter the name as Sales Threshold.
4. Select Data Type as Integer.
5. Enter the Current Value as 1000.
6. Click OK.
7. Right-click the parameter and select Show Parameter.
8. Right-click in the Data pane and select Create → Calculated Field.
9. Enter the following formula:
Calculated Field: Sales Status
IF SUM([Sales]) >= [Sales Threshold]
THEN "High Sales"
ELSE "Low Sales"
END


10. Drag Sales Status into Colour.
11. Change the parameter value to observe the changes.
Result: Successfully created sets, applied sorting and filtering, and used parameters in Tableau.

Procedure E: Creating Calculated Fields
1. Open the Data pane.
2. Right-click in an empty area.
3. Select Create → Calculated Field.
4. Enter the field name as Total Profit.
5. Enter the following formula:
SUM([Profit])


6. Click Apply and then OK.
7. Create another calculated field named Profit Status.
8. Enter the formula:
IF SUM([Profit]) > 0
THEN "Profit"
ELSE "Loss"
END


9. Drag Profit Status into Colour.
10. Drag Total Profit into Rows to display the calculated values.
Important Tableau Calculated Field Formulas
Purpose	Formula
Total Sales	SUM([Sales])
Average Sales	AVG([Sales])
Total Profit	SUM([Profit])
Profit Ratio	SUM([Profit])/SUM([Sales])
Total Quantity	SUM([Quantity])
Category Status	IF SUM([Sales])>1000 THEN "High" ELSE "Low" END
Discount Check	IF [Discount]>0 THEN "Discounted" ELSE "No Discount" END
Order Year	YEAR([Order Date])

Procedure B: Aggregation and Granularity
1. Open a new worksheet.
2. Drag Category into Columns.
3. Drag Sales into Rows.

5. Click the Sales pill and select Measure → Average.

8. Add Region to Rows to increase the level of detail.
9. Remove Region to decrease the level of detail.
10. Compare the results.
Important Aggregation Functions
Function	Formula	Purpose
SUM	SUM([Sales])	Calculates total
AVG	AVG([Sales])	Calculates average
MIN	MIN([Sales])	Finds minimum
MAX	MAX([Sales])	Finds maximum
COUNT	COUNT([Sales])	Counts records with non-null values
COUNTD	COUNTD([Customer ID])	Counts unique customers
ATTR	ATTR([Category])	Returns a single value if consistent

Granularity: Granularity means the level of detail present in the data or visualization.

Example:
- Category-wise Sales = Lower level of detail.
- Category-wise and Region-wise Sales = Higher level of detail.
